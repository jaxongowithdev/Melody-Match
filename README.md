# Cadence Room

A complete offline teacher for everyday pauses. Ten original sessions, five skill cards, three breathing rhythms and a private recap journal.

Complete onboarding, walk the session on Walk, run Four columns, browse Range and save a Tablet note. All lessons, preferences, history and notes are local. No account, login, cloud sync or remote AI.

The iOS app and metadata use `com.app.cadenceroom.build`. Metadata: `com.app.cadenceroom.build.json`. Existing SQLite filenames remain compatible with previous installations.

Run `flutter analyze` and `flutter test` at the package root. In `example`, run `flutter test test/widget_test.dart` or the integration test on an iOS simulator.

The externally hosted support and privacy URLs are preserved. The privacy URL currently refers to Mosslight; publish or supply a Cadence Room policy before store submission. No submission was performed.
